Features
-
- List of trackers
- Tracker detail page with latitude and longitude
- CoreData persistence
- Polling for coordinates
- Map with real-time updates
- Pull to refresh
- Encryption for session hash
- Console logging of http calls
- Offline/Online/Loading indicator
- Snackbar for load error

How to start
-
1. Use XCode 26+
2. iOS 26 recommended (iOS 18 also supported, but looks uglier)
3. Open `/GPSTraking.xcodeproj`
4. Run regular build on simulator or device
